# Scheduling Footprint Experiment

This package runs a controlled, simulator-only experiment for the manuscript's
scheduler term. It does **not** embed images and does **not** transmit real
network traffic.

## Conditions

- `cover`: benign protocol-cover timing generated by a bounded-delay process.
- `unshaped`: nearly periodic three-channel protocol timing.
- `shaped`: protocol timing processed by an admissible bounded-delay scheduler.

The representative protocol parameters match the manuscript:

- sliding window `W = 5`;
- heartbeat cadence `h = 10`;
- skew tolerance `Delta = 100 ms`;
- timeout `tau = 2 Delta = 200 ms`;
- scheduler delay budget `rho = 100 ms`.


The paper mode uses 10,000 epochs per seed and condition, seeds 42/43/44,
1,000 KS bootstrap replicates, 1,000 MMD permutations, and 200 classifier
permutations.

## Interpretation

KS, MMD, and timing-classifier advantage are empirical scheduling-footprint
proxies associated with `epsilon_sched(sigma*)`. They are not direct estimates
of the total-variation term in the composition theorem.

The default experiment is controlled and synthetic. For the strongest journal
claim, a later extension should replace the synthetic cover process with
captured benign application traces while retaining the same analysis script.
