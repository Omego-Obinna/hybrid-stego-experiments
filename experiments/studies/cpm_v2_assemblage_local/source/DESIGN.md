# Fixed native comparison panel

This panel was fixed before production generation or any held-out classifier score. Full settings, source and input hashes are in run_config.json. All original upstream files remain in the workspace phase6 upstream directory. The copied source/operational_adapters.diff explains every compatibility adapter: pinned local model path, owned temporary file, fresh fixture-key configuration for Assemblage, and an equivalent bool-to-int conversion required by NumPy 2 / bitarray. The native sampler, ECC and message/packet algorithms are unchanged. Sage runtime copies keep preparsed/generated files outside frozen source.

Pulsar panel: 200 source groups, 100/40/60 training/validation/test, three fixed application payloads of 128/256/384 bytes. Both revised CPM and native Pulsar are attempted for every group. Native 256-pixel RGB 16-bit Pulsar images retain native Sage region ECC and have benign references produced by the same sampler, with identical PNG serialization. CPM uses native 512-pixel BOSSBase covers and its unchanged three-frame protocol. Comparing net application bytes does not imply equal bpp, native format, pixel budget or protocol service. Detector features are fixed native-precision image-content statistics; family/parameters/orientation/threshold are fixed on validation, shared-family choice across sources is explicit, and test is used once. Every secondary family is retained. Complete valid groups condition both methods symmetrically, with fixed minimum counts. Native capacity or recovery failures are never retried or replaced.

Assemblage panel: ten development source groups per message size, three sizes (1024/2048/4096 bytes), native church model / original region ECC / MTU 408 / RaptorQ repair fraction 0.5. Original PDQ lookup and saved local offline state are used. All offline candidates, capacity skips, sent carriers, native decoder exceptions and wrong packets stay recorded. A native decode exception among received images aborts a message, as in the upstream receiver. No ground-truth oracle removes incorrect packets. Saved clean native packet outcomes are replayed under fixed iid object-erasure probabilities 0/0.1/0.2/0.3 and five seeds. A CPM object is one native authenticated frame and an Assemblage object is one image; sizes/counts are reported rather than silently equated. Zero-loss repetitions and shared source groups are not independent trials. No online platform or third-party messaging is used.

Cost reporting separates native carrier bytes, CPM JSON/base64 frame bytes and public objects, and Assemblage offline shared state/hash-bank bytes. Generated carriers have no original-cover PSNR/SSIM. CPM-specific cross-channel CP-UNL is not defined for the single-carrier Pulsar or native Assemblage interfaces; missing scores are not zero. This is finite empirical evidence, not a universal cryptographic, deployed-network, scheduler or anonymity guarantee.

Preproduction development checks passed independent Pulsar byte recovery with native 16-bit serialization, original Assemblage packet send/PDQ lookup/recovery plus RaptorQ message reconstruction, fixed-feature known-leak controls in both classifier families, and revised CPM's matched-byte receiver. Development fixtures differ from every production key/seed/message. Production failures are preserved without retry.
