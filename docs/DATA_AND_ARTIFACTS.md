# External data and artifacts

The Git archive contains source code, numerical tables, small saved prediction
arrays, configurations and verification/provenance records. It is not a complete
binary image/checkpoint deposit. See `provenance/excluded_artifacts.json` for
the census of excluded run directories and `source_manifest.json` for included
file digests. Existing verification/configuration receipts retain source,
image, input and checkpoint digests where they were recorded.

| Resource | How to supply it / why it is external |
|---|---|
| BOSS cover images and exact study subsets | Obtain the dataset under its terms; match cover IDs and hashes in the supplied cover manifests. Generated/attempted carriers are not regenerated by release checks |
| Generated carriers, full feature matrices, public views | Preserve or obtain the author's run artifact archive; these are needed for native extraction or new forward passes |
| Selected and last detector checkpoints | Obtain the matching checkpoint archive and verify saved digests; prediction-only checking does not require them |
| Cover-text corpora and exact stream splits | Obtain source texts under their terms, then match recorded split/stream hashes; corpus names alone do not recover exact preprocessing |
| Generator weights and native baseline runtime | Use the exact upstream revision/configuration in the native run records; weight downloads are not bundled |
| Native STC implementation / SLIC package state | Install separately; original binary/launch provenance is incomplete and remains disclosed |
| Private fixture master keys / protected receiver state | Intentionally excluded. Generate new keys for new experiments; do not publish or reuse research keys as deployment credentials |
| Very large per-epoch transport / embedding logs | Use the author archive if needed. The saved aggregate and corrected unique transport scenario tables are included |

No public large-artifact URL or DOI has been invented. The manuscript's data
availability statement and any eventual external deposit should describe what
the author actually hosts and can lawfully redistribute. Publishing this Git
archive alone does not provide full native checkpoint/image replay.

Raw records for the five-method study retain all attempts. Baseline records
without independently established extraction are labelled as such; the fresh
known-message panel supplies a separate recovery/timing denominator. Do not
merge these fields into an unsupported perfect-recovery count.
